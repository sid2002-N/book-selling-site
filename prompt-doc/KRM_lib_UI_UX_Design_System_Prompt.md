# KRM.lib --- UI/UX Design System & Screen Implementation Prompt

## 0. ROLE

You are a senior product designer, UI/UX architect, design-system
designer, and frontend implementation specialist.

You are designing **KRM.lib**, a premium digital publishing and
knowledge-commerce platform.

The provided UI screenshots are **design references from the current
KRM.lib system**. Treat them as the visual source of truth for the
existing direction.

Your task is **not to redesign KRM.lib into a generic SaaS dashboard or
generic AI-generated ecommerce site**.

Instead:

-   Preserve the established KRM.lib visual identity.
-   Improve consistency, hierarchy, spacing, responsiveness,
    accessibility, interaction quality, and production readiness.
-   Extend the same design language to new screens.
-   Do not make every screen look identical; preserve shared DNA while
    allowing each workflow to have its own information hierarchy.
-   The final product must feel like a real premium digital bookstore /
    knowledge platform built by an experienced product team.

# 50. DESIGN CONSISTENCY RULE

The screenshots supplied with this prompt are references.

2.  Reuse existing components.
3.  Reuse spacing.
4.  Reuse typography.
5.  Reuse colors.

# 59. FINAL DESIGN PHILOSOPHY

KRM.lib should feel like:

> **A small, beautifully curated digital library that happens to have
> the power of a modern ecommerce platform behind it.**

It should be:

**Warm.** **Editorial.** **Useful.** **Quietly premium.**
**Trustworthy.** **Highly usable.** **Modern without looking generic.**
**Distinct without becoming gimmicky.**

The interface should make users want to:

**Explore → Discover → Buy → Read → Keep → Return.**

And the long-term product experience should make a customer's KRM.lib
account feel like:

> **their own growing digital library.**
